# 白虎 · White Tiger

將本資料夾整個複製至 Codex 的 `pets` 目錄：

- Windows：`%USERPROFILE%\.codex\pets\`
- macOS / Linux：`~/.codex/pets/`
- 已設定 `CODEX_HOME` 時：使用該目錄下的 `pets` 子資料夾。

確認 `pet.json` 與 `spritesheet.png` 位於同一層。在支援自訂寵物的 Codex 桌面版中，重新整理自訂寵物清單並選擇「白虎」。功能是否可用取決於平台與 Codex 版本。

預覽：以瀏覽器開啟上層的 `white-tiger-preview.html`。

素材：透明 PNG，1536 × 2288 px，8 欄 × 11 列，每格 192 × 208 px，`spriteVersionNumber: 2`。請保留尺寸與排列。

可免費個人使用與修改；分享時請保留專案名稱、來源連結與授權文字。完整說明與授權見本專案：
https://github.com/pin0501/codex-white-tiger-pet

## English

Copy this entire folder into Codex's `pets` directory: `%USERPROFILE%\.codex\pets\` on Windows or `~/.codex/pets/` on macOS / Linux. If you set `CODEX_HOME`, use its `pets` subfolder. Keep `pet.json` and `spritesheet.png` together.

Refresh the custom pet list in a supported Codex desktop version and select **白虎**. Availability depends on your platform and Codex version.

Open `white-tiger-preview.html` in the parent folder for an offline preview. Preserve the sprite dimensions and cell layout when editing. See the project link above for installation details and personal-use permission.
